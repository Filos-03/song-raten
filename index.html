Einmalige Einrichtung

Damit die Seite mit deinem Spotify spielen darf, brauchst du eine kostenlose „App“ im Spotify-Entwicklerbereich. Das dauert ca. 2 Minuten.

  1. Öffne developer.spotify.com/dashboard und melde dich mit deinem Spotify-Konto an.
  2. Klicke auf Create app. Name und Beschreibung sind egal (z. B. „Song-Raten“).
  3. Bei Redirect URIs genau diese Adresse eintragen und auf Add klicken:
  4. Bei Which API/SDKs are you planning to use? Web API und Web Playback SDK anhaken, speichern.
  5. In den App-Einstellungen die Client ID kopieren und hier einfügen:

Wichtig: Zum Abspielen im Browser braucht Spotify ein Premium-Konto. Die Client ID wird nur in diesem Browser gespeichert.
