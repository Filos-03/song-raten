# 🎵 Song-Raten

Errate Songs aus deinen eigenen Spotify-Playlists – zuerst hörst du nur 0,5 Sekunden.
Länger hören oder ein falscher Tipp kostet eine Chance.

**Spielen:** Seite öffnen, mit Spotify anmelden, Playlist wählen.

Voraussetzungen:
- Spotify **Premium** (Spotify erlaubt die Wiedergabe im Browser nur mit Premium)
- Chrome, Edge oder Firefox
- Dein Spotify-Konto muss vom Betreiber der Spotify-App freigeschaltet sein (Entwicklermodus)

Lokal starten: `start.bat` ausführen und `http://127.0.0.1:8888/` öffnen.
